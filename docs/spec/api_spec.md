# API Специфікація — SportBook UA

## Базова URL: `/api`

## Автентифікація
Використовується JWT Bearer токен. Токен передається в заголовку:
```
Authorization: Bearer <token>
```

## Статуси бронювань
- `pending_payment` — очікує оплати
- `confirmed` — підтверджено
- `cancelled` — скасовано
- `completed` — завершено

## Категорії локацій
- `tennis` — тенісний корт
- `football` — футбольне поле
- `pool` — басейн
- `gym` — тренажерний зал
- `other` — інше

## Коди відповідей
- `200` — успішно
- `400` — некоректний запит
- `401` — не авторизовано
- `403` — доступ заборонено
- `404` — не знайдено
- `422` — помилка валідації
